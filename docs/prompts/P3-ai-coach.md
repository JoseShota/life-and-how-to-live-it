# Phase 3 prompts — AI Coach

Prereqs: Phase 2 done (auth). An Anthropic API key stored as a **Supabase secret** (`supabase secrets set ANTHROPIC_API_KEY=...`). Never in the frontend.

## P3-1 Edge function
```
Create supabase/functions/coach/index.ts (Deno). Verify the Supabase JWT; reject anonymous.
Actions: 'parse' | 'brief' | 'review'. Use the official Anthropic SDK; look up current model IDs in the
Anthropic docs (fast/cheap model for 'parse', stronger model for 'brief'/'review').
Use tool-use / JSON schema output for 'parse' so the response is strictly typed.
Simple per-user rate limit (e.g. 100 calls/day in a table). Return errors as JSON.
Client wrapper src/ai/coach.ts. No key or model call from the browser.
```

## P3-2 Natural-language quick add
```
On Today, add a single "⚡ Quick add" input. Send text + context (areas with ids/short names,
accounts with ids/names, today's date, categories) to coach 'parse'. Expected output union:
{type:'expense'|'income', amount, accountId, category, areaId?, date, description}
| {type:'quest', title, areaId, difficulty, priority, dueDate?}
| {type:'session', areaId, minutes, date}
| {type:'habit', habitKey, value}.
Show an editable preview card; on confirm, save via existing engine functions (so XP flows).
Examples to support (Spanish and English): "gasté 230 en tacos con crédito 2", "me pagaron 8000 de Weaving",
"quest: calificar parciales mañana, difícil", "trabajé 2h en freelance", "dormí 7.5".
```

## P3-3 / P3-4 Briefing & weekly review
```
Morning brief: on first open after 05:00 each day, show a dismissible card generated by coach 'brief'
from aggregates only (quests due, cards due ≤5d with debt, streaks at risk, yesterday's hours, pipeline next actions)
plus the user's strategy summary (hard-code a 10-line summary of docs/00-MASTER-PLAN.md in the function).
Cache per day in settings. Weekly review: button on /review sends 7-day aggregates; display wins, leaks,
and exactly 3 hour reallocations between areas. Never send raw notes or transaction descriptions unless the user opts in.
```
